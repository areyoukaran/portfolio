DD

DropDock

01

Ephemeral file, text, and image sharing, no signup required. Upload something and get a self-destructing link and QR code that expires by time, download count, or a single view. The one-download links are race-safe: if two people hit the same link at the same instant, an atomic SQL update guarantees exactly one of them succeeds, not both. A Celery-based sweep clears expired drops in the background instead of blocking requests.

FastAPI React PostgreSQL Celery Redis S3 / MinIO
